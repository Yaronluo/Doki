# 首版验收与证据清单

> 当前清单只验收 tvOS 客户端与必要 Hub；iPhone/Mac 客户端后置。未勾选代表尚未验证。当前实际结果见 [CURRENT_STATE](../handoff/CURRENT_STATE.md)。局部 build、fixture 或模拟器结果不自动勾选首版验收项。

## 1. 工程与界面

- [ ] 仅 tvOS 工程可重复生成、构建和启动；没有额外 iPhone/Mac target，命令、scheme、destination 和签名方式已记录。
- [ ] tvOS 原生标签/焦点、遥控器选集/源/弹幕操作和返回恢复可用。
- [ ] TV 完整发现、追番、日历、搜索、我的/设置、详情/选集和播放器，不止占位入口。
- [ ] 左上角头像/收起式透色磨砂导航与白色焦点条；自定义控件无 Liquid Glass 反光/透镜层，普通背景与操作层材质克制。
- [ ] 边缘方向呼出、侧栏切换/收起、内容焦点恢复；热门自动/手动轮播、暂停/恢复、离线保留与辅助功能分支可用。
- [ ] 浅/深色、长标题/缺图、空列表、动态字体、减少透明度/动态效果与高对比度均可用。
- [ ] 快速进入/返回、刷新晚到图片、重复选择不会串条目、闪空或抢焦点；录屏证明中断行为。
- [ ] 与上游截图不同但符合 Doki 页面层级可通过验收；视觉相似度不作标准。

## 2. 播放、源与状态

- [ ] 固定正确章节映射，真实单源完成一集；TV 的设备、系统、编码/封装与网络都记录。
- [ ] 首/中/尾 seek、暂停/继续、退出重开续播、后台/前台恢复正确。
- [ ] direct 与 relay 的失败阶段可区分；过期地址可复验，切源次数有界，取消后旧任务不恢复播放器。
- [ ] 不同剪辑源不静默按相同秒数续播，手动修正路径可操作。
- [ ] 订阅更新保持内部源 ID、手动偏好和映射；不兼容条目禁用并解释原因，快照可回滚。
- [ ] 原生字幕/音轨可切换；PiP/AirPlay 在可用设备和网络验证恢复，未测能力有明确边界。

## 3. 登录与同步

- [ ] 所有者一次性登记、电视配对批准/领取不可重放，六位码不独立授予访问权限。
- [ ] Hub 轻量网页允许普通浏览器辅助配对和邮箱/密码/验证码登录，无需另一 Doki App 或 OAuth 应用密钥；LAN/VPN 可达、CSRF/一次性凭证验证、App/日志无上游 token；真实账号完整链路通过。
- [ ] token 刷新串行并原子保存；授权失效暂停回写，设备撤销使其会话失效。
- [ ] 主动回看允许进度变小；旧 epoch/乱序/重复事件不覆盖新会话。
- [ ] 手动取消已看之后，旧自动完成和旧 outbox 重试不把它改回。
- [ ] 事务回滚、并发提交与同步分页不丢变更；游标过期重建快照保留未确认事件。
- [ ] Bangumi 真实单集 PUT 与批量 PATCH 契约通过；失败/冲突可重试或选择保留状态。

## 4. 弹弹play与渲染

- [ ] Doki 自己的 AppId/AppSecret 已配置；未配置、403、额度和业务错误分别展示，未借用参考项目凭据。
- [ ] 签名测试区分 SHA256 二进制 Base64、HMAC 和 hex；Path 不含 query；日志脱敏。
- [ ] 302 加速域名与重定向有限，鉴权头不泄露到未批准 origin。
- [ ] Bangumi 条目映射失败/错误时可手动选正确弹幕库；源剪辑偏移独立存储。
- [ ] int64 ID 不经过 JS 浮点精度损失；非法 p、未知模式、重复 cid、超大文本被受控处理。
- [ ] 滚动/顶部/底部、开关、密度、字号、透明度、区域、偏移在 TV 均可用遥控器操作。
- [ ] pause、seek、倍速、切集、切源、后台返回与窗口尺寸变化后按媒体时间重新定位，不补跑墙钟积压。
- [ ] 弹幕避让黑边、字幕和系统控件；密集时有确定性降密度，记录帧率和峰值内存。
- [ ] 弹幕服务超时/无数据/未配置时视频正常起播，已有内容不被错误清空。
- [ ] PiP/AirPlay 不带自绘弹幕的边界准确，正常播放恢复后重新定位；没有引入烧录。
- [ ] README 与关于页有“弹弹play开放弹幕网络”和官网来源，TMDB 署名符合当次要求。

## 5. 部署与恢复

- [ ] LAN 域名/TLS/DNS/实际媒体吞吐验证；VPN 若启用再验证其路由和重叠网段；未把 Hub API 开到公网。
- [ ] provider/浏览器/媒体/图片所有出站走同一政策；私网、IPv6、DNS 变化和重定向绕过测试通过。
- [ ] API/Worker readiness、超时回收、进程重启与断连取消正确。
- [ ] 数据库/密钥恢复实际演练，Redis 丢失不丢已确认进度与 outbox。
- [ ] 用户实际设备安装/更新可重复，卸载与数据清理范围明确；未承诺未经验证的签名有效期。

## 6. 证据粒度

| 证据类型 | 可以证明 | 不能据此宣称 |
|---|---|---|
| 文档检查 | 链接/表格/示例结构有效 | 工程可运行、API 可用 |
| Fixture/领域测试 | 固定输入和特定并发场景正确 | 源站当前存活、账号授权成功 |
| Build | 目标配置通过编译/链接 | 真机可安装或完整播放 |
| 截图 | 当前画面/层级/材质表现 | 动画可中断、持续帧率达标 |
| 录屏/性能记录 | 指定设备场景的交互、动画和时间轴 | 所有设备/所有源全部可用 |
| 真实 API/完整集播放 | 当时账号、源、设备和网络上的结果 | 外部站点长期稳定或大样本成功率 |

证据建议保存在被忽略的 `.local/artifacts/<任务ID>/<日期>/`，交接文档写文件位置与摘要，不提交含 Cookie、账号标识或带签名 URL 的原始日志。需要版本化的 fixture 必须自造或脱敏且来源允许。

### REWORK-004 焦点与背景专项

- [ ] 深色普通背景有蓝灰亮度与内容色，发现页滚离横幅后不变成黑底。
- [ ] 透色大圆角导航、胶囊焦点条与原有上/左呼出、右/下离开行为一致；磨砂仅覆盖侧栏，右侧横幅/文字/海报无额外模糊或蒙层。
- [ ] 筛选、日期、设置行、弹幕与源选择聚焦时只有一套焦点形状，无额外白色胶囊遮字；检查相邻项边界与浅/深色。


### REWORK-005 首页与货架专项

- [ ] 首页只有“立即播放”，未登录没有继续观看；页点居中，无来源标签/数量/左右箭头教学。
- [ ] 首次选择在当前货架上方预览，不改变热门身份；焦点保留原海报，再次选择详情及返回正确，菜单键收起预览。
- [ ] 头像昵称胶囊原位展开/收回；下方隐藏后左边缘仍能呼出；连续快速方向键可中断，不影响右侧清晰度。
- [ ] 浅/深色、减少动态效果/透明度分别检查；真实横幅与缺图都有可读回退。模拟器证据不代替真机遥控器/帧率或实播。
